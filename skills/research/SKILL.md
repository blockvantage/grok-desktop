# Research skill

## Method

1. Restate the question and success criteria.
2. Gather facts; separate **fact / inference / unknown**.
3. Cite sources with URLs or titles when available.
4. Produce a structured note: summary, key findings, risks, next steps.

## Output shape

- `research-brief.md` with headings and a short executive summary on top.
- Bullet lists over dense prose.
- Explicit “confidence” notes when evidence is thin.

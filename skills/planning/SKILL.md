# Planning skill

## Style

- Protect focus: few priorities, clear owners, next actions.
- Surface only high-leverage nudges.
- Prefer weekly narrative + open loops over endless task lists.

## Output

- Prioritized plan with time horizons (today / this week / later).
- Explicit blockers and decisions needed from the user.

4. Architecture decisions

  • Pure logic first: skill resolve, presets, suggestions, license crypto, and manifest parse are unit-tested without Electron.
  • License service: HMAC keys GD1.<payload>.<sig>, machine-bound activation, 7-day offline grace; optional HTTP server for later hosting.
  • Defaults never block users: bundled skills always merge; custom paths append.
  • Worktree isolation: ~/blockvantage/worktrees/grok-desktop-intelligence on branch feat/intelligence-skills-commerce.
